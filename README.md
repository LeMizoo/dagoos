# 🚀 Dagoo's - La mobilité connectée... Chez les potes, ça roule.

**Dago** = surnom des Malgaches. **Dagoo's** = "Chez nous", "Entre nous".

## Structure du projet

- `/backend` : API Node.js (déployé sur Render)
- `/frontend` : Apps web (déployé sur Cloudflare Pages)
- `/mobile` : PWA chauffeurs (déployé sur Cloudflare Pages)
- `/docs` : Documentation
- `/assets` : Images, polices, icônes

## Slogan officiel

> "La mobilité connectée... Chez les potes, ça roule."

## Technologies

- Backend : Node.js / Express / Prisma / PostgreSQL
- Frontend : React / Vite / Cloudflare Pages
- Mobile : React / Capacitor / PWA
